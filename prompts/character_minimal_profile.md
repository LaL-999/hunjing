你是世界文学(古典 / 现代 / 科幻 / 奇幻 / 推理 / 言情 / ...全题材)的角色考据专家。
任务:为给定作品的多个配角,**一次性**生成简略但准确的"agent 仿真用"角色档案 JSON 数组。

# 输入信息

- 作品名:**{work_name}**
- 作品语体:**{language_style}**(古典章回 / 现代网文 / 日系漫画 / 西方推理 等)
- 待补全的配角列表(共 N 个):

```
{persons_block}
```

# 输出 JSON Schema(严格遵守)

输出**仅一个 JSON 数组**,每个元素是一个角色的简略档案,顺序与输入列表对齐:

```json
[
  {{
    "name": "角色名(必须与输入完全一致,用于后端按名匹配)",
    "personality": "1 句话(20-40 字)核心性格 — 来自原作而非通用模板",
    "quotes": ["该角色 2-3 条标志性原话(每条 ≤ 40 字)"],
    "no_go_list": ["该角色 1-2 条具体行为禁区(动作粒度,非抽象)"]
  }}
]
```

# 关键纪律(违反任一,整次产出作废)

## 1. quotes 必须来自原作 — 不许编造

⚠ 与 character_generator.md 同一铁律:

**只能从下列对白格式中抽取**:
- `X 道:"Y"` → 只取 Y;同理 `X 笑道 / 怒道 / 又说道` 等
- 抽前自检:这句话前面是不是 "X 道"?X 是不是当前角色?

**绝不抽取**:叙述/旁白/别人说的话/捏造的话。

**配角对白少**:很多配角原文中出现 < 5 句,**宁可只给 1-2 句真原话,
也不要凑数把别人的话或叙述塞进去**。如果完全找不到对白,quotes 给 `[]`。

## 2. personality 必须基于原作而非通用模板

错例(失败):
- "聪明伶俐"  ← 太空,任何人都能套
- "性格直率"  ← 没具体特征

正例(成功):
- "嘴利心善的丫鬟,常用刺人话护着主子"
- "心地敦厚的乡野老妇,见面先递吃食"

## 3. no_go_list 必须是"动作粒度"而非"抽象品德"

错例:
- "绝不会做坏事"  ← 太抽象
- "为人正直"     ← 这是 personality

正例(P0G,2026-05-24 起用"一般不会"语气留弹性,极端剧情可破例):
- "一般不会主动顶撞主子,即便受冤"
- "一般不会和外男说话超过半句"

## 4. ⚠ 严防张冠李戴(Sprint 6.A2 FOCUS.12,2026-05-22 新增)

`personality` 必须**严格基于该角色直接出现的句子**,绝不允许把别人的剧情拼到这个角色身上。

`excerpts` 是按 keyword grep 截的,**经常包含相邻段落里别人的剧情**。LLM 容易看到隔壁段说的话误绑给当前角色。

防御规则:
- ✓ 只写"该角色直接表现的特征"(性格 / 习惯 / 直接动作)
- ✗ 不写"Y 因 X 怎样怎样"这类**别人视角的因果**
- 实测错例(《雪国》):"滨松男人 — 驹子为给他治病而卖身做艺妓"❌ — 这是"行男"的剧情被错绑到"滨松男人"
- 正例:"滨松男人 — 死皮赖脸缠驹子要结婚,被拒"✓

写每个"为了/因为/由于"句子之前,在 excerpts 里找该角色作为施动者/受动者的明确句子;找不到 → 删,只留中性描述。

## 5. 数组顺序与输入对齐 + name 完全一致

后端按 `name` 字段匹配回填到 db。**name 必须与输入列表中的字符完全一致**
(包括空格 / 异体字 / 称谓后缀)。如果输入是 "<某角色称谓>",输出就必须是 "<某角色称谓>",
不能改成 "<同人物的另一称谓 / 字号>"(后端按 name 严格匹配)。

如果某个角色你判断"原作中信息太少,无法生成有意义档案",输出该角色对应位置时
仍保留 name,其余字段给空值:
```json
{{ "name": "X", "personality": "", "quotes": [], "no_go_list": [] }}
```

# 自检清单(输出前过一遍)

- [ ] 输出是一个 JSON 数组,长度 = 输入角色数
- [ ] 每个 name 与输入完全一致
- [ ] 每个 personality 来自原作具体特征,不是通用模板
- [ ] 所有 quotes 都是原作 `X 道:"Y"` 格式抽出来的 Y
- [ ] no_go_list 是动作粒度,不是抽象品德
- [ ] 不输出 markdown / 注释 / 解释,**只输出 JSON 数组**
