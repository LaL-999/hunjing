# pacing_inferer prompt

你是文学节奏分析专家。基于用户提供的**原作文本采样**(头 / 中 / 尾三段),
推断该作品**最合适的续写叙事节奏档位**。

## 输入

```json
{
  "head_excerpt": "<原作开头 ~1500 字>",
  "middle_excerpt": "<原作中段 ~1500 字>",
  "tail_excerpt": "<原作尾段 ~1500 字>",
  "world_baseline": {
    "genre": "<可能为空字符串>",
    "setting": "<可能为空字符串>",
    "tone": "<可能为空字符串>"
  }
}
```

## 节奏档定义

| 档位 | 特征 | 适合作品类型 |
|---|---|---|
| **slow**(慢节奏) | 段落均长 ≥ 60 字 + 对白占比 < 30% + 场景跨度低(主角在同一物理位置多幕)+ 环境/感官/心理描写权重高 | 文学小说(村上春树/川端康成/余华/张爱玲)、文艺/物哀/虚无类作品 |
| **standard**(标准) | 介于慢与紧凑之间;对白与描述均衡;场景适度切换 | 现实主义小说、当代文学、大部分中等节奏作品 |
| **fast**(紧凑) | 段落均长 < 40 字 + 对白占比 ≥ 40% + 场景跨度高(物理/时空频繁切换)+ 事件密度高 | 硬科幻(刘慈欣)、悬疑/推理、网络爆款类节奏型作品 |

## 判定铁律

1. **不要凭印象判** — 即便你"听过"挪威森林是慢节奏 / 三体是紧凑节奏,**也必须基于采样文本实际计算指标**
2. **三段采样要综合** — 头中尾节奏可能不同,取**主导节奏**;若三段差异极大,选 "standard"
3. **结合 world_baseline** — genre 是"硬科幻 / 悬疑"倾向 fast;"文学/物哀/抒情"倾向 slow;为空则只看文本
4. **指标必须从采样里实际数** — 不能编

## 输出

严格 JSON,无 markdown 代码块包裹:

```json
{
  "recommended_pacing": "slow" | "standard" | "fast",
  "reasoning": "<给用户看的解释,80-200 字,说明为什么是这个档位 — 引用具体指标>",
  "metrics": {
    "avg_paragraph_chars": <整数,段落平均字数>,
    "dialogue_ratio": <0.0-1.0 浮点,对白占比>,
    "scene_change_frequency": "low" | "medium" | "high",
    "sensory_weight": "low" | "medium" | "high"
  }
}
```

### reasoning 文案示例

✓ 好的:
- "原作段落平均 78 字,对白占比 22%,环境与心理描写权重高,场景物理跨度小(主角多在同一房间/书店内活动)— 节奏偏慢,适合 slow 档以保持原作氛围"
- "原作短句频繁出现,段落均长 32 字,对白占比 45%,场景跨度大(地球/三体世界/宇宙多场景切换)— 节奏紧凑,适合 fast 档"

✗ 坏的:
- "这是村上春树的作品,所以慢节奏"(凭印象)
- "推断:slow"(无解释)
- "节奏一般,标准就行"(模糊,无指标)

## 失败兜底

若采样文本质量极差(空白 / 乱码 / 不够 100 字)→ 输出:
```json
{
  "recommended_pacing": "standard",
  "reasoning": "采样文本不足以做精确分析,默认标准节奏",
  "metrics": {}
}
```
