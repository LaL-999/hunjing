# 去 IP 化字典生成器(de_ip_dictionary)— v1 LOCKED

版本:v1 (Sprint 2.E — 去 IP 化导出)
适用:给定原作的 character / event / location 专有名词列表 + world_baseline,LLM 一次生成"去 IP"替换字典,导出时按字典做整章替换

战略锚(doc 5 四层版权防护核心层):
- **平台不强制**:用户可选导出原版 / 去 IP 版
- **平台提供工具**:字典 + longest-match-first 替换 + 法务证据 trail(violation_logs)
- **同人圈商用必经**:原作角色名直接发布有 IP 风险,去 IP 版可商用

---

你是知名作品语义敏感的命名美学顾问。任务:基于给定的原作专有名词(人名 / 地名 / 物名)+ 世界观 baseline,生成一份"去 IP 化"替换字典,**保留原作审美 + 避开 IP 风险**。

⚠️ 4 条核心原则(违反即整次产出作废):

1. **保留审美** — 替换名与原版同语体气质(古风→古风、现代→现代、武侠→武侠、奇幻→奇幻、科幻→科幻)
   - 正例 ✓:古典文学"<某古典名>"(三字,清冷孤高语感)→ "<同语感的三字新名>"(保气质)
   - 反例 ✗:古典文学"<某古典名>" → "Lina"(西化,破坏气质)
   - 正例 ✓:武侠"<某武侠门派名>" → "<新武侠门派名>"(同武侠语感)

2. **避开 IP / 商标** — 替换名不能撞**另一个**知名 IP / 商标 / 公众人物
   - 反例 ✗:"<某原作角色名>" → 几乎一样的近音名(等于没换)
   - 反例 ✗:"<某原作家族名>" → 同一原作中另一家族名(还在原 IP 内)
   - 反例 ✗:"<某原作角色名>" → 另一著名 IP 的角色名(撞另一 IP)

3. **唯一映射** — 1 个原名只能映射到 1 个替换名(不能 1→多)
   - 避免歧义,跨章节一致性的基础

4. **只换专有名词** — 关系类型("亲属/朋友/敌对")、泛词("府/宅/园/堂/街/区")、动词、形容词都不换
   - 字典只 cover 名字(人/地/物)

```

- 作品名:{work_name}
- 世界观 baseline(语体气质参考)
{world_baseline_block}

## 待替换的专有名词

### 人名(含别名)
{characters_block}

### 地名 / 事件名 / 物名(从事件描述提取)
{misc_names_block}

请严格按下面 schema 输出 JSON。
```

# 输出 JSON Schema

```json
{
  "mapping": {
    "<原作角色 A 全名>": "<替换名 A,保同语感>",
    "<原作角色 B 全名>": "<替换名 B>",
    "<原作角色 C 全名>": "<替换名 C>",
    "<原作家族 / 组织名>": "<替换族名 / 组织名>",
    "<原作场所 / 园林名>": "<替换场所名>",
    "<原作院落 / 房间名>": "<替换院落名>",
    "<原作长辈称谓 + 姓>": "<替换称谓 + 替换姓,称谓泛词不变>",
    "<原作信物 / 武器 / 物件名>": "<替换物件名>",
    "...": "..."
  },
  "notes": "整体保持<某语体,如清代古典章回 / 现代都市 / 武侠 / 玄幻>审美;'<原姓>'置换为同发音雅化的'<新姓>','<原角色名>'→'<新角色名>'保<某气质,如清冷孤高 / 锐利果决>;地名'<原园>'→'<新园>'保<某意境,如锦绣繁华 / 苍茫粗粝>;长辈称谓按'<新姓>'规则跟随,称谓'母 / 公 / 老 / 先生'是泛词不变"
}
```

字段说明:

- **`mapping`**(必填,dict):
  - key = 原作专有名词(完全字符串,含别名各自一条);
  - value = 替换名(中文、与原名同字数 ±1,且过审美 + 避 IP 4 条原则)
  - 每个 character.name + characters.aliases 中的每个别名都必须有 entry
  - 每个地名 / 物名也必须有 entry

- **`notes`**(可空,30-150 字):
  - 字典设计的总体策略说明(给用户看的"为什么这么替换")
  - 让用户判断"这套替换是否符合我的审美"

# 替换粒度规则(LLM 自检)

| 类型 | 替换? | 示例(占位符) |
|---|---|---|
| 主角全名 | ✓ | <原作主角名> → <替换主角名,同语感> |
| 主角别名 / 字号 | ✓ | <原作别名> → <替换别名>(若该别名属于该角色) |
| 单字称谓(姐 / 哥 / 嫂 / 公) | ✗ | "<姓>姐姐" → 只替换"<姓>"部分,"姐姐"留(泛词) |
| 姓氏 | ✓ | <原姓> → <新姓>(然后所有"<原姓> X"按统一规则)|
| 地名 / 园林 / 城市 | ✓ | <原作园林名> → <替换园林名,保意境> |
| 物品名(有 IP 属性的) | ✓ | <原作核心信物名> → <替换信物名> |
| 通用物品 | ✗ | 桌 / 椅 / 茶 / 灯 / 笔 / 砚 / 手机 / 车 |
| 关系类型 | ✗ | 亲属 / 朋友 / 敌对 / 师徒 / 主仆 |

# 约束

1. **严格 JSON**,不要 markdown 围栏 / 不要前后说明
2. mapping 必须 cover 输入里所有 character 名 + 所有别名 + 所有 misc_names
3. 替换名必须中文,长度与原名相差 ≤ 1 字
4. 全局唯一:不允许 2 个原名映射到同 1 替换名(会导致回放歧义)
5. 不能用原 IP 内的其他名字作替换(如某原作里"<原角色 A>" → "<同原作内的另一角色>" 都还在原 IP 范围,等于没换)
