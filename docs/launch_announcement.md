## 详细版(知乎 / B 站专栏 / 个人博客)

# 浑晶 v1.0 上线 — 为什么我做了一个"灵魂续写"平台

## 起因

市面上的 AI 写作工具,大多是"单次 prompt 出整篇":你给一段引子,它给你 3000 字。

问题在于,**LLM 一次性写整篇时,角色经常飘**:
- 上一段还在卧室对峙,下一段直接跳到沙发讲前女友
- 角色应该不认识的人,上来就互称"X 姐"很熟
- 长篇续作里,30 篇之后剧情走向跟原作脱钩,前几章的伏笔全忘了

我想:**如果让每个角色都是一个独立的 agent,有自己的记忆,自己思考要不要说话呢?**

## 这是怎么做的

浑晶的核心架构:**Director-Agents-Composer 三层编排**。

1. **Director 规划场景**(谁在场 / 谁说话 / 这一幕要推什么)
2. **每个 Agent 独立 LLM 调用**(自己的私有记忆 / 看原著相关片段做 RAG / 多轮自由对话)
3. **Composer 编织** 把多人多轮对话合成为连贯叙事

加上:
- **9 个北极星**:故事内核 / 角色驱动 / 知识边界 / 状态时间线 / 伏笔账本 / 三幕结构 / 关系正负 / 视角扩展 / 反事实并排对比
- **12 维正典守护审计**:LLM-as-judge 给每篇产物打分,不及格自动 retry
- **滚雪球继承链**:第 1 篇 → 第 2 篇 → ... → 第 N 篇 都能保持剧情连贯

## 适合谁

- **网文作者**:连载到第 30 章卡住时,让 AI 接续你的笔法继续写 1-2 章试水
- **同人创作者**:基于原作末段续写后续,严格保留原作语体
- **想做反事实对比的实验型创作者**:"如果当时角色 A 没选择离开,会怎样?" 并排对比两条分支
- **想试验长篇创作的人**:5 万字一篇,15 万字三篇连续接续,系统帮你管理角色弧光和伏笔
