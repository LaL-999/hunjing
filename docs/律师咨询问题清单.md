# I. Tier S · 阻塞类(决定商业模型成立与否)

## 问题 1:公版作品图谱跨用户复用的合规性

**业务背景**:
我们的成本控制有一项关键设计——**对公版作品(如《红楼梦》《西游记》《福尔摩斯》
早期作品)只解析一次,生成的知识图谱(实体+关系结构化数据)在所有用户之间共享**。
这把单用户成本从 ¥5-10 压到 ¥0.1-0.5(降幅 95%+),是订阅定价能盈利的根基。

**预设答案**:我们认为这合规,因为:
- 公版作品本身已无著作权保护
- 我们存档的是"实体名称、关系类型、事件描述"等**结构化的事实信息**,不是原文片段
- 这种结构化提取类似于维基百科上的剧情总结,不构成对原作的实质性占用

**希望律师明确**:
- ✅ 上述判断是否成立?有无司法判例支持?
- ⚠️ 如果不成立,我们可以采取哪些技术 / 法律措施(如:图谱中限制原文引用比例、
  仅存"角色 A → 角色 B"的关系类型不存事件细节)使其合规?
- ⚠️ 这一判断在不同作品类型上(古典小说 / 民国作品 / 公版未久作品)是否有差异?

**为什么是 Tier S**:
**这一答案直接决定我们的成本模型是否成立**。否定 → 单用户成本 10× 上升 →
订阅定价(38/268 元)结构性破产 → 整个商业模式重做。

# II. Tier A · 关键类(决定核心架构与对外定调)

## 问题 2:"工具能力定价"的避风港效力

**业务背景**:
我们的核心法律站位是——**平台只售卖"工具能力"(算力、模型调用、agent 深度等),
不售卖"创作权"或"演绎权"**。类比 Photoshop 卖软件订阅,但不为用户用 PS 修改迪士尼
海报承担责任。详见附件 doc 11 第六条第一项。

**预设答案**:这一站位让平台落入《信息网络传播权保护条例》第二十二条避风港范围。

**希望律师明确**:
- ✅ "工具能力定价" 这个表述能否在司法上构成对平台"中立性"的有效定性?
- ⚠️ 平台**同时是工具提供方又是生成内容产生方**(LLM 调用是平台主动发起的),
  这个事实是否会破坏避风港抗辩?有无判例(尤其 AI Dungeon 类、AIGC 类案件)?
- ⚠️ 如果用户上传的是**第三方有著作权的作品**(非公版),平台生成的衍生内容
  涉及 OOC 角色 / 原作设定,平台被起诉时,**"工具能力定价"+"用户上传声明"+
  "平台不存档原文" 三层防护是否足以转移责任到用户?**

**为什么是 Tier A**:这决定了我们对外宣传 / 商业定位的核心叙事是否站得住。
如果律师否决,我们要重新设计法律叙事(可能要走"作者授权分成"模式)。

## 问题 3:用户协议引用《独立价格说明》的法律有效性

**业务背景**:
为保留商业灵活性,我们把具体价格 / 配额 / 字数等数字从协议主体中剥离,放进单独
发布的《浑晶服务等级与价格说明》,在协议第六条第二项以引用方式纳入。详见附件
doc 11 第六条修订思路。

**预设答案**:依《民法典》合同编关于格式条款的规定,只要"显著标识"+"用户已知悉",
引用应合法有效。

**希望律师明确**:
- ✅ 单纯协议中引用是否足够,还是必须**用户首次订阅前以独立勾选确认《价格说明》**
  才有效?
- ⚠️ 如果价格说明独立修订(不走协议变更程序),**已订阅用户能否被绑定新版本**?
  我们在协议中已设"提前 30 日通知 + 不利调整退订权"——这套设计是否完整覆盖
  司法实践要求?

**为什么是 Tier A**:这影响**我们后续调价 / 调配额的运营成本**。如果律师否决,
我们每次调价就要走完整法务流程,商业反应速度大幅下降。

## 问题 4:自动配额降级机制的消费者权益合规

**业务背景**:
当用户当月配额接近上限时,系统自动进入"节能模式"——生成速度降低、agent 数量压缩、
高级功能暂时不可用。详见附件 doc 11 第六条第四项。

**预设答案**:我们做了**事先告知 + 比例相称 + 保留升级路径** 三项配套设计,
应符合《消费者权益保护法》要求。

**希望律师明确**:
- ✅ 上述三项配套是否已经足够,还是有**额外的事先告知形式要求**(如:必须在订阅
  确认时强制弹窗,而不仅协议条款)?
- ⚠️ 自动降级是否构成"单方变更服务标准"?如果构成,有无被消保协会大规模投诉的
  现实风险?
- ⚠️ 我们在节能模式下保留"登录、查看、导出、退款"等非生成性权利,这是否足以让
  自动降级被定性为"附条件履行" 而非"违约"?

**为什么是 Tier A**:这条直接关系**用户上线后投诉率**。一旦被批量投诉到消保协会,
诉讼成本和舆论代价会击穿利润空间。

## 问题 5:演绎作品的"法律责任转移到用户"机制是否生效

**业务背景**:
协议第三条至第五条 + 上传时强制确认弹窗 + 生成内容归用户所有 + 平台不存档,
四层联合的目标是把演绎作品的版权责任**完全转移到用户头上**。详见附件 doc 8 第二章 +
附录确认弹窗。

**预设答案**:四层联合应能让平台在"用户违法上传 + 用户公开传播衍生内容"两个
高风险场景下,把责任主体从平台转移到用户。

**希望律师明确**:
- ✅ 这套责任转移机制能否在中国司法实践中**有效阻挡平台被列为共同被告**?
  特别是著作权人起诉时(原告往往倾向告平台,因为平台有钱)。
- ⚠️ "用户上传时勾选声明" 的电子证据效力如何?是否需要额外做**实名认证 / 短信验证 /
  人脸识别** 才有强证据效力?
- ⚠️ 平台**未指纹拦截**(指纹库覆盖不全,用户上传了主流网文)的情况下,平台是否
  会因"未尽合理审查义务" 被认定共同侵权?指纹库需要做到什么覆盖率才算"合理"?

**为什么是 Tier A**:这条决定**单个侵权诉讼的胜败概率**。如果责任转移失败,平台
每场被诉成本(诉讼费+律师费+赔偿+商誉) 5-50 万,十次就能击垮初创公司。
