## 段落一 · 开场钩子(0:00 – 0:30,30 秒)

### 口播

"2026 年的现在,有上亿中国人正在网上读小说、看漫画、追番剧。其中的每一个人,
都至少有过一次这样的经历——你追了三年的小说断更了,你最爱的角色在最后一页死了,
你心中那个版本的结局,作者从来没有写出来过。

这种感觉在中文里有一个专门的词,叫**意难平**。

我今天要讲的,是一个让所有人都能写出自己那个版本的工具,叫**浑晶**。"

### 画面

- 黑底白字,只有四个字:**意难平**
- 字体:霞鹜文楷,慢慢淡入
- 第二张:**浑晶**(产品 logo,水晶几何形)+ 拼音 HunJing

### 表演笔记

- "意难平"三个字念出来时,整个人停顿一秒
- 念到"浑晶"两个字,语速放慢,让品牌名钉进投资人记忆
- 这是全场你和投资人之间唯一的纯情感时刻,不要急着进数据

## 段落二 · 问题与市场(0:30 – 1:30,1 分钟)

### 口播

"中国网文市场年规模超过 400 亿人民币,活跃用户接近 5 亿。漫画、日漫、
日系小说的中文受众加起来又是几亿。这些数字大家都知道。

但藏在这个数字背后的事实是:**头部小说平台的烂尾投诉率超过 30%,断更超过半年的
连载作品占比超过四成。漫画和番剧延期、烂尾、停更的比例只多不少。**

这意味着每年有上亿次"我心里那个故事没有结局"的事件在真实发生。

那这些读者怎么办?今天他们的选择只有两个——要么忍着,要么自己写同人。前者是
大多数,后者是极少数,因为写一篇能看的同人,需要重读原作十遍、做几万字考据、
有持续创作的笔力。

这中间有一个**巨大的、从来没有被任何工具填补过的空洞**——读者的创作冲动远大于
他们的创作能力,这个差值就是浑晶要做的市场。"

### 画面

- 三个数字阶梯式跳出:
  - 网文市场 400 亿 + 漫画/日漫数亿用户
  - 烂尾/断更/烂尾投诉 30%+
  - 1 亿想续写 vs 100 万真能写
- 最后一帧:倒金字塔图

### 表演笔记

- 数字念得平稳但有力,不要兴奋
- "巨大的、从来没有被任何工具填补过的空洞"这句要明显放慢

## 段落四 · 差异化定位(3:00 – 3:45,45 秒)

### 口播

"市场上已经有几类相邻产品。我用 30 秒讲清楚我们和它们的区别。

**第一类是 ChatGPT、Claude 这种通用 AI 写作工具**。它们能写,但它们不知道贾宝玉是
谁、贾府的礼仪是什么。我们用 prompt 工程把作品的世界规矩(像闺阁宵禁、嫡庶礼法)
深度内化到每一个 agent 的行为约束里。**它们生成的是"AI 风格的文字",我们生成的是
"这个世界里本就该发生的故事"**。

**第二类是 MiroFish 这种多 agent 仿真平台**。它们让 agent 模拟真实社会、预测真实
事件,目标是"算准未来"。我们做的事情完全相反——**我们让 agent 进入虚构世界,目标
是让一个不存在的故事变得动人**。它们用 agent 做分析,我们用 agent 做创作。

**第三类是 AI Dungeon 这种文字冒险游戏**。它们让用户和 AI 共同创造新世界。但我们
做的不是创造新世界,**是为已存在的世界续命**——这是我们最深的护城河,因为已存在
的世界里有亿万读者的情感投资,这种投资是任何新世界从零开始都无法复制的。"

### 画面

```
                  通用 AI    多Agent仿真    AI Dungeon    浑晶
理解原作世界观      ✗           ✗             ✗          ✓
角色独立思考        ✗           ✓             部分        ✓
情感连接深度        低          低            中          高
为已有作品续写      ✗           ✗             ✗          ✓
```

## 段落五 · 商业模型(3:45 – 4:30,45 秒)

### 口播

"我们怎么赚钱?讲这件事之前我必须先说一句——**这一类 AI 内容产品最常见的死法不是
没人用,是用户越多亏得越多**。每一次仿真背后是真金白银的 token 成本,定价算错了,
获客等于破产。

我们的做法是**反向设计:先把成本结构调到健康,再倒推定价**。三件最关键的事:

第一,**关键 agent 用顶级模型、配角用低端模型**,把单次推演的成本压到原来的三成。

第二,**公版作品只解析一次,所有用户共享同一份图谱**——红楼梦只算一次账,服务一万
个用户。

第三,**算力配额耗尽时自动降级而不是停服**,既防止重度用户拖垮成本,也保留向上
升级的动机。

订阅基础档位 38 元每月,超级档位 268 元每月,精确权益由前 100 位种子用户的真实
使用数据校准。**目标毛利率底线 35%。** 我们还设计了按次购买的算力包作为高毛利
现金流补充。

法务结构——避风港、用户协议、版权处理——已经完整,法律文档草稿已就绪,
正在寻找律师做最终审核。"

### 表演笔记

- "用户越多亏得越多"这句要明显放慢,做一秒停顿
- "我们不靠拍脑袋定价"那句话其实没说出来,但隐含——投资人能感觉到

## 现场表演纪律(同 v1,务必守住)

1. **节奏比内容重要**——850 字 / 5 分钟。任何超字临场发挥都是减分
2. **Demo 是命门**——失败立刻切备用录屏,不解释不道歉
3. **不主动谈估值**——被问就答"根据合作意向再谈"
4. **衣着**——"有质感的休闲",不穿西装也不穿连帽衫
5. **最后那句"意难平这件事,中国人讲了一千年"练到稳**——这是投资人记得住的最后一帧
